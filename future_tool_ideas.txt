## NEW CATEGORY: SECURITY (/security-tools)

### S1. Image Steganography Tool ✅ COMPLETE
- **Category**: security-tools (NEW)
- **Search Volume**: 110K/mo — "steganography online" (40K), "hide text in image" (45K), "image steganography tool" (25K)
- **Description**: Hide secret text inside PNG/JPG images via LSB (least-significant-bit) encoding. Extract hidden text from stego-images. Optional AES-GCM password layer for extra encryption.
- **Features**: Encode text in image, decode from image, optional password, preview both images, download stego-image.
- **Status**: ✅ COMPLETE — Fully implemented with LSB steganography, AES-256-GCM encryption, React component, SEO-optimized page, unit tests passing.
- **Build**: Medium. Canvas API + bitwise ops, crypto.subtle for AES.
- **Client-side**: 100%
- **Top 3 competitors**: stylesuxx.github.io/steganography, futureboy.us/stegano, 8gwifi.org
- **URL**: /security-tools/image-steganography

### S2. EXIF Metadata Viewer & Remover
- **Category**: security-tools
- **Search Volume**: 450K/mo — "exif viewer" (180K), "remove exif" (135K), "exif data" (135K)
- **Description**: Drag image → view GPS/camera/date metadata, one-click strip all metadata, re-download clean image.
- **Features**: View all EXIF tags (GPS coords, camera make/model, date, orientation), remove all or specific tags, batch processing, before/after comparison.
- **Why build**: Privacy tool — strong AEO/GEO for "how to remove location from photo." Daily use by journalists, Facebook sellers, dating-app users.
- **Build**: Low. Use exifr or piexifjs library.
- **Client-side**: 100%
- **Top 3 competitors**: exifdata.com, verexif.com, exif.tools

### S3. URL Safety Checker / Phishing Detector
- **Category**: security-tools
- **Search Volume**: 680K/mo — "is this link safe" (300K), "url checker" (210K), "phishing link checker" (170K)
- **Description**: Paste a URL → check against Google Safe Browsing, PhishTank, domain age, SSL cert status, redirect chain, IP reputation.
- **Features**: Real-time scan, threat types shown (malware/phishing/deceptive), redirect trace, domain WHOIS date, SSL grade.
- **Why build**: Massive intent, repeat usage, trust-building. No direct equivalent in our web-tools.
- **Build**: Medium. Needs APIs (Google Safe Browsing free tier + Cloudflare Workers for WHOIS/redirects).
- **Client-side**: No (requires API)
- **Top 3 competitors**: virustotal.com, urlvoid.com, sucuri.net/sitecheck

### S4. Private Self-Destructing Notes (Encrypted Pastebin)
- **Category**: security-tools
- **Search Volume**: 320K/mo — "privnote alternative" (40K), "self destructing note" (90K), "encrypted pastebin" (120K), "send secret message" (70K)
- **Description**: Write note → generates one-time URL → note encrypted in-browser (AES-GCM) with key in URL fragment (never sent to server) → destroys after first read.
- **Features**: Client-side encryption, key-in-fragment (zero-knowledge), self-destruct on read or after N hours, optional password, QR code for sharing.
- **Why build**: Viral sharing mechanic — every link shared = inbound visit. High repeat usage.
- **Build**: Medium. Client-side AES-GCM + Cloudflare KV for ciphertext storage.
- **Client-side**: Hybrid (encryption client-side, only ciphertext stored)
- **Top 3 competitors**: privnote.com, onetimesecret.com, scrt.link
