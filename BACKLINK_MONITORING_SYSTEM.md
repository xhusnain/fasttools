### **Free Tools (Essential)**

#### **Google Search Console**
- **Purpose:** Official Google backlink data
- **Setup:** Connect to website
- **Metrics:** Referring domains, top linking sites, anchor text
- **Frequency:** Daily monitoring
- **Cost:** Free

#### **Google Analytics**
- **Purpose:** Traffic and referral analysis
- **Setup:** Connect to website
- **Metrics:** Referral traffic, user behavior, conversions
- **Frequency:** Daily monitoring
- **Cost:** Free

#### **Ubersuggest**
- **Purpose:** Basic backlink analysis
- **Setup:** Create account and connect domain
- **Metrics:** Backlink count, referring domains, domain authority
- **Frequency:** Weekly monitoring
- **Cost:** Free (limited)

#### **Answer The Public**
- **Purpose:** Content and keyword monitoring
- **Setup:** Create account
- **Metrics:** Content opportunities, keyword trends
- **Frequency:** Weekly monitoring
- **Cost:** Free (limited)

### **Paid Tools (Recommended)**

#### **Ahrefs (Primary Tool)**
- **Purpose:** Comprehensive backlink analysis
- **Setup:** Connect domain and set up alerts
- **Metrics:** Backlink profile, referring domains, anchor text, link velocity
- **Frequency:** Daily monitoring
- **Cost:** $99/month

#### **SEMrush**
- **Purpose:** Competitor analysis and backlink monitoring
- **Setup:** Connect domain and set up campaigns
- **Metrics:** Backlink profile, competitor analysis, keyword tracking

- **Cost:** $119/month

#### **Moz Pro**

#### **Majestic SEO**
