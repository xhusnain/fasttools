## What Are Agent Skills?

At its core, an **Agent Skill** is a reusable package of instructions that teaches your AI agent how to perform specific tasks. Think of it as a custom plugin or a "playbook" that you define once and your agent can recall whenever needed.

![Google Antigravity Agent Skills Interface](/images/blog/google-antigravity/agent-skills-interface.png)

Technically, a skill is simply a directory containing a `SKILL.md` file. This file uses YAML frontmatter (defining the skill's `name` and `description`) followed by natural language instructions, code snippets, or step-by-step guides.

When you’re in a conversation with Antigravity, the system automatically detects these skills. If your request matches a skill's description, the agent essentially "downloads" that knowledge and executes the task according to your custom playbook.

### How to Create Your First Skill

Creating a skill is straightforward:

1.  **Create a Directory:** Navigate to you project's `.agent/skills/` folder (for project-specific skills) or `~/.gemini/antigravity/skills/` (for global skills). Create a new folder, e.g., `feature-scaffold`.
2.  **Add SKILL.md:** Inside that folder, create a file named `SKILL.md`.
3.  **Define Metadata & Instructions:**

```markdown
---
name: feature-scaffold
description: Generates a boilerplate structure for a new feature component.
---
# Feature Scaffold Skill

When the user asks to "scaffold a new feature":
1. Ask for the feature name.
2. Create a directory with that name.
3. specific files: index.ts, style.css, and component.tsx.
...
```

Once saved, just refresh your Antigravity chat. The agent will now recognize "feature scaffold" as a discrete capability!

## Agent Manager: Your Mission Control

Antigravity isn't just a chat window; it's a full-featured environment. The IDE introduces a split interface:

*   **The Editor:** Your standard coding workspace.
*   **The Agent Manager:** A dedicated dashboard to spawn and oversee multiple AI agents working in parallel.

This "Mission Control" allows you to assign high-level tasks (e.g., "Refactor authentication", "Write unit tests") to separate agents. You can watch them execute complex workflows simultaneously, greatly accelerating your development velocity.

### Global vs. Workspace Skills

Antigravity offers two scopes for your agent skills, giving you granular control over your AI's behavior:

*   **Workspace Skills (`.agent/skills/`):** Specific to your current project. Use these for repo-specific conventions, architecture rules, or project-only scripts.
*   **Global Skills (`~/.gemini/antigravity/skills/`):** Available across *all* your projects. Perfect for your personal coding style, favorite testing patterns, or universal workflows.

*Pro Tip: Start by creating a skill in your workspace. Once you've refined it, move it to your global folder to take that superpower with you everywhere.*

## Enhanced Safety: Secure Mode

With great power comes the need for control. The update introduces **Secure Mode**, a setting designed to "provide enhanced security controls for the Agent."

![Antigravity Secure Mode Settings](/images/blog/google-antigravity/secure-mode_settings.png)

When enabled, Secure Mode restricts the agent's ability to:
*   Access external resources (like the open web).
*   Execute arbitrary shell commands without approval.
*   Perform sensitive file system operations.

This is particularly useful when working in enterprise environments or on confidential projects where you want to ensure the AI doesn't accidentally leak data or run unchecked scripts. It puts the human firmly in the loop for every critical action.
