## Step 1: The Love Box (HTML) 💌

First, we need a container for our tool. We'll make a card that holds the input field and the calculate button. We'll give it an ID of `love-calc-card` so we can style it later.


We also need an `<input type="date">`. This gives us a nice calendar dropdown automatically in almost every browser. No complex plugins required!

**What's happening here?**
*   `div id="love-calc-card"`: Think of this as the picture frame. It groups everything together so we can hang it on the wall (or in this case, style it on the page) as one unit.
*   `input type="date"`: The browser handles all the calendar logic for us. You don't need to build a calendar from scratch!
*   `onclick="calculateLove()"`: This connects our button to the name of the function we'll write in the next step.


```html
<div id="love-calc-card">
  <h2>❤️ Love Calculator</h2>
  
  <label>When did it start?</label>
  <input type="date" id="start-date-input">
  
  <button onclick="calculateLove()">Calculate Duration</button>
  
  <div id="love-result" style="display:none;"></div>
</div>
```

## Step 2: The Logic (JavaScript) 🧠

Dates in programming can be tricky, but modern JavaScript makes them easier. We need to:
1.  Get the "Start Date" from the user.
2.  Get "Today's Date".
3.  Subtract them to find the difference in time.

Here is the core function. We'll use a simple approximation for this tutorial to keep it beginner-friendly, calculating the total difference in milliseconds and then converting it roughly to years and days.

**Understanding the Code:**
*   `new Date(inputVal)`: This turns the text string "2023-01-01" into a powerful Date object the computer understands.
*   `Math.floor()`: This simply rounds down integers. So 5.9 days becomes 5 days.
*   `now - start`: When you subtract two dates in JavaScript, you get the result in *milliseconds* (thousandths of a second).


```javascript
<script>
function calculateLove() {
    var inputVal = document.getElementById('start-date-input').value;
    if(!inputVal) { alert("Please pick a date!"); return; }

    var start = new Date(inputVal);
    var now = new Date();
    
    // Difference in milliseconds
    var diff = now - start;
    
    // Convert to days (1000ms * 60s * 60m * 24h)
    var days = Math.floor(diff / (1000 * 60 * 60 * 24));
    
    // Simple year calculation
    var years = Math.floor(days / 365);
    var remainingDays = days % 365;

    // Show result
    var resultText = "You've been together for " + years + " years and " + remainingDays + " days!";
    document.getElementById('love-result').innerText = resultText;
    document.getElementById('love-result').style.display = 'block';
}
</script>
```
