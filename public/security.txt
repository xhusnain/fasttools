# Security Policy
# We take security seriously. If you discover a security vulnerability, please report it responsibly.

# Reporting Process
# 1. Email us at security@smarttoolboxes.com
# 2. Include detailed information about the vulnerability
# 3. Allow reasonable time for us to respond and fix the issue
# 4. Do not disclose the vulnerability publicly until we've had a chance to address it

# What We're Looking For
# - Cross-site scripting (XSS)
# - SQL injection
# - Authentication bypass
# - Data exposure
# - Server-side request forgery (SSRF)
# - Any other security issues

# What We're NOT Looking For
# - Social engineering attacks
# - Physical attacks
# - Denial of service attacks
# - Issues that require physical access to the server
